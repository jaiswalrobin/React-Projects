ℹ️ About This App

🔒 Privacy First

Media streams are peer-to-peer encrypted. No server ever sees your video or audio.

💸 Zero Cost

No backend, no hosting fees. Uses free PeerJS cloud for peer discovery only.

🎓 Educational

Perfect for learning WebRTC. See how peer-to-peer connections work without infrastructure.

Built with PeerJS • WebRTC • Tailwind CSS
